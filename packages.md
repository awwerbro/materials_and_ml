# Packages

Useful packages and tools for ML in materials science. Primarily Python, but contributions in other languages are welcome.

| Package | Description | Link |
|---------|-------------|------|
| Ax | Adaptive experimentation platform for Bayesian optimization and generation strategies; useful for designing experiments and tuning models. | https://ax.dev/docs/generation_strategy |
| Kinisi | Bayesian analysis of diffusion, conductivity and related properties from molecular dynamics simulations; handles temperature-dependent data with proper error propagation. Discussed in [April 20, 2026 meeting](meetings/2026-04-20.md). | https://github.com/kinisi-dev/kinisi |
| pyepal | Python implementation of epsilon-PAL, a multi-objective active learning algorithm for Pareto front exploration. | https://pypi.org/project/pyepal/ |
| PySR | Symbolic regression in Python and Julia; discovers interpretable mathematical expressions from data. | https://github.com/MilesCranmer/PySR |
| SHAP | SHapley Additive exPlanations is a game theoretic approach to explain the output of any machine learning model. | https://shap.readthedocs.io/en/latest/ |
