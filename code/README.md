# Code

Code examples, tutorials, and notebooks relevant to ML in experimental materials science.

## Contributing

Every contribution lives in its own subfolder. Each subfolder should contain:

- A `README.md` describing what the code does and how to run it
- Notebooks (`.ipynb`) and/or scripts (`.py`)
- Any data files needed to run the code

Example structure:

```
code/
  my-contribution/
    README.md
    notebook.ipynb
    data.csv
```

Open a pull request to add your contribution.
